# Course Routing Map

Canonical course routing table for **The Curriculum**, parsed dynamically at runtime by `workspace_catalog.py` to resolve `LectureIdentity`, canonical header subjects, and environment-configured OneDrive delivery folders (`TAFREEGH_ONEDRIVE_BASE`).

Architectural decisions: [ADR 0004](../../../../docs/adr/0004-numbered-lecture-routing-and-stem-matching.md), [ADR 0005](../../../../docs/adr/0005-lecture-identity-and-dynamic-routing-ssot.md), and [ADR 0009](../../../../docs/adr/0009-retire-context-md-into-glossary-and-course-routing.md).
